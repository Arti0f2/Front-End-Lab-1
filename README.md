# CodeNest

Навчальний вебпортал для вивчення мов програмування.

У лабораторній роботі 1 використовується HTML, а в лабораторній роботі 2 сторінки стилізовані зовнішньою таблицею CSS.

## Структура

- `index.html` — головна сторінка з описом порталу, навчальною інформацією та розділом для лабораторної роботи 3.
- `topics.html` — каталог із навчальними темами у вигляді карток.
- `feedback.html` — форма зворотного зв'язку з валідацією.
- `css/common.css` — спільні базові стилі, кольорові змінні та навігація.
- `css/home.css` — стилі головної сторінки й розділу лабораторної роботи 3.
- `css/topics.css` — стилі сторінки навчальних тем.
- `css/feedback.css` — стилі сторінки зворотного зв'язку.
- `css/style.css` — зведений файл стилів для зворотної сумісності.
- `js/lab3.js` — обробка наборів тем (масиви, функції) і користувачів (ООП) для лабораторної роботи 3.
- `js/main.js` — додаткові скрипти для форми зворотного зв'язку.

## Запуск

У VS Code натисніть `F5` і виберіть конфігурацію «Запустить CodeNest в Chrome». VS Code запустить локальний сервер і відкриє головну сторінку.

Або запустіть у терміналі з кореня проєкту `python -m http.server 8080 --bind 127.0.0.1` і відкрийте <http://127.0.0.1:8080/>.
