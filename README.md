# CodeNest

Навчальний вебпортал для лабораторної роботи 1 з HTML на тему вивчення мов програмування.

У першій лабораторній використовується лише HTML-розмітка без CSS та JavaScript. Сторінки навмисно побудовані у стилі ранніх вебсайтів із таблицями. CSS і JavaScript збережені як резерв для наступних лабораторних.

## Структура

- `index.html` — головна сторінка з описом порталу, списком завдань, таблицею та контактами.
- `topics.html` — каталог із п'ятьма навчальними темами.
- `feedback.html` — форма зворотного зв'язку з валідацією.
- `css/style.css` — резервні стилі для наступних лабораторних, зараз закоментовані.
- `js/main.js` — резервний JavaScript для наступних лабораторних, зараз не підключений.

## Запуск

Відкрийте `index.html` у браузері. Для локального сервера у VS Code можна використати Live Server або виконати `python -m http.server` у корені проєкту.

Проєкт не потребує встановлення залежностей.
